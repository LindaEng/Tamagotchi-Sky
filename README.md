# Tamagotchi-Sky

A small color-screen Tamagotchi built with an Arduino Nano.

## Features

- exercise / coding / music stats
- stat decay over time
- interactive buttons
- sprite animations (planned)
- portable battery powered device

## Hardware

- Arduino Nano
- 1.3" TFT ST7789 display
- LiPo battery
- 3 buttons

## Development

Currently testing logic on Arduino Uno before moving to Nano.

## Future Plans

- animated sprite system
- mood states
- evolution system
- 3D printed case
